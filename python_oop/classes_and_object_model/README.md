# Python - Classes and Object Model

This project introduces Object-Oriented Programming (OOP) in Python.

## Learning Objectives

- Understand classes and objects
- Create instances of classes
- Use the __init__ method
- Define instance attributes and methods
- Understand private attributes
- Use getters and setters with properties
- Validate object attributes
- Use special methods such as __str__
- Understand basic encapsulation
- Model simple objects using classes

## Files

- Square classes
- Size validation
- Area calculation
- Getters and setters
- Square printing
- String representation
- Rectangle classes
- Rectangle area and perimeter
